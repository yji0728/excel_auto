데이터 흐름:
───────────────────────────────────────────────────────────────────────

1. 사용자 입력 (GUI)
        ↓
2. 워크플로우 엔진 (Workflow Engine)
        ↓
3. 엑셀 조작 (Excel Operations)
        ↓
4. 외부 라이브러리 (openpyxl, pandas)
        ↓
5. 엑셀 파일 (Input/Output)


주요 기능 흐름:
───────────────────────────────────────────────────────────────────────

파일 열기:
  GUI → Workflow Engine → Excel Operations → openpyxl → Excel File

워크플로우 실행:
  GUI → Workflow Engine → 각 단계 실행 → Excel Operations → 결과 반환

데이터 처리:
  Excel File → openpyxl → Excel Operations → pandas → 처리 → 다시 저장
